# ビリヤード（v306）

緑フェルト、木枠、金の金具、象牙色の数字玉を使う独立モード。

- `table.webp`: 提案画像を参照して画像生成した盤面（800×1200）。玉・キュー・照準・演出は Canvas。v303以降の画像は変更なし。
- 初期盤面は数字12個＋白い玉1個、すべて未結合。1×3、2×2、3×3、4×2、5×2をシャッフルし、接触しない12か所に配置。
- 数字どうしは合計10以下なら結合し、元の数字を保つ剛体として移動・回転。10超過は反発。白い玉は結合しない。
- **白い玉が結合した塊に触れると全解除。** 全構成数字を元の位置で個別の玉へ戻す。接触の勢いと小さな分離運動を与え、同じ塊の玉どうしには0.8秒の再結合猶予を設ける。操作の切り替えや専用ボタンは不要。
- 15点先取。通常テンクルの `calcPts` と同じ配点：役なし1、ワンペア2、ツーペア3、スリーカード4、ストレート5点。5＋5は役なし。ストレートは1・2・3・4。同じ数字3個以上はスリーカード。
- **役なしも含め、10を作り続ける限り同じ人の手番。** 連続回数の上限はなく、10を作れなかったときに交代。プレイヤー・AI共通。1打で複数の10ができれば各得点を加算するが、打球回数の貯金はしない。15点に達した場合は勝利で終了。
- **次に打つ人を先に決め、その反対側が10で消えた数字を置き直す。** 動きがすべて止まってから、実際に使った数字を1個ずつ未結合で返す。1・2・3・4なら4個、5＋5なら2個。1打で複数完成した場合はすべての構成数字を返す。配置中も次の打者を表示。
- AIの完成後はプレイヤーが盤面をタップして配置。プレイヤーの完成後はAIが配置する。次に置く数字と残りの数字は下のトレーに表示。玉との重なり、クッション外、配置担当以外の入力は拒否。全個数を置き終えるまで打球不可。
- 最後の配置が終わったら、得点した人の追加打球か次の人の手番へ進む。勝利した場合は再配置せずリザルトへ。自動補充は廃止し、盤面＋配置待ちの数字12個を維持する。
- AIは3段階。プレイヤーと同じ物理計算で試射し、得点・追加打球・崩れ方を評価。配置も次に打つ側と作りやすさを考えて決める。
- 打球は盤面のどこからでも引っぱって離す。開始位置の18 CSS px以内へ戻して離すと中止。引っぱり中だけ下部にキャンセルボタンを表示し、その上へ指を動かして離す方法でも中止できる。別の指でボタンを押す操作にも対応。配置はタップ、または押したまま動かして離す。
- キーボード：打球は左右で角度、上下で強さ、Spaceで打つ。引っぱり中のEscapeは打球キャンセル。配置は矢印で位置、Enter/Spaceで置く。
- SEは打球、衝突、壁、結合、全解除、配置、役完成、追加打球、勝敗を合成。ミュート・停止・退出に対応。役演出は金の輪・細粒・役名と得点。決定打も見えるようリザルトを1.65秒遅らせる。

検証：`node tests/billiards.cjs`。全解除、元の数字・個数の保存、双方の配置、重なり・停止中の拒否、5種類の役と役なしの追加打球、双方8連続成功後の失敗による交代、次の打者を基準にした配置担当、複数完成、15点勝利、AI、35打の物理安定性を確認。ブラウザーでも実際の4連続完成・タップ配置・追加打球、元の位置／キャンセル領域／Escapeでの取り消し、タッチでの取り消しと2本指操作、一時停止、再戦、スマホ幅での表示を確認。
