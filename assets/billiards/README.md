# ビリヤード（v307）

緑フェルト、木枠、金の金具、象牙色の数字玉を使う独立モード。

- `table.webp`: 提案画像を参照して画像生成した盤面（800×1200）。v303以降の画像は変更なし。玉・キュー・照準・演出はCanvas。
- 数字玉は **1〜5が各2個、合計10個**。白い玉1個は別。未結合の状態でシャッフルして開始。補充による数字の追加はしない。
- 数字どうしがぶつかると結合し、元の数字を保った塊として移動・回転する。
- **ちょうど4個で合計10になった場合だけ得点して消える。** 通常テンクルの `calcPts` を使用。この在庫で成立する役はワンペア2点、ツーペア3点、ストレート（1・2・3・4）5点。各数字が2個なのでスリーカードは成立しない。
- **10超過はバースト。** 5・2の塊に4なら、その3個が消えて配置待ちになる。4個未満で10、4個で10未満、塊どうしで5個以上になった場合もバースト。点数は入らず、手番は交代する。他の玉の位置は変更しない。
- **白い玉が塊に触れると全解除。** 元の位置で個別の玉へ戻し、接触の勢いと小さな分離運動を与える。同じ塊の玉どうしには0.8秒の再結合猶予。これはバーストではなく、その場で分離するだけ。
- 成功し続ける限り連続回数に上限なく同じ人が打つ。成功しなかった場合、またはバーストした場合は交代。同じ一打で成功とバーストが両方起きた場合、得点は維持して交代する。打球回数の貯金はしない。
- 動きがすべて止まったら、次に打つ人を決定。**完成した4個は次の打者の相手が配置し、バーストした玉は次の打者自身が配置する。** 消えた元の数字を1個ずつ返す。両方が同じ一打で起きた場合も、配置待ちの理由ごとに担当を切り替える。
- 配置は盤面のタップ、または押したまま動かして離す。担当分だけを下部に表示。重なり・盤外・担当以外・停止中の入力は拒否。全配置が終わるまで打球不可。配置中も次の打者を表示する。
- 15点先取。勝利判定は打球の動きが止まったところで行い、勝利時は再配置せずリザルトへ。盤面＋配置待ちの在庫は常に1〜5各2個を維持。
- AIは3段階。プレイヤーと同じ4球完成・バースト・全解除の物理で試射し、得点・続行・バーストを評価。配置は次の打者が自分なら作りやすく、相手なら作りにくい位置を評価する。
- 打球は盤面のどこからでも引っぱって離す。**開始位置の24 CSS px以内へ指を戻して離せばキャンセル。** キャンセルボタンや専用領域は置かない。引っぱり中は既存の説明1行を操作案内に切り替えるだけ。画面外へ引っぱる操作もポインターキャプチャで継続。
- キーボード：左右で角度、上下で強さ、Spaceで打球。引っぱり中のEscapeでキャンセル。配置は矢印で位置、Enter/Spaceで置く。OSによる操作中断やポインターキャプチャ喪失でも打たない。
- SEは打球・衝突・壁・結合・全解除・バースト・配置・役完成・追加打球・勝敗を合成。ミュート・停止・退出に対応。バーストは短い低音と控えめな輪、役完成は金の輪と得点演出で区別。リザルトは停止後1.65秒待つ。

検証：`node tests/billiards.cjs`。数字10個の内訳、4個限定の完成、成立する各役、双方7連続成功と交代、各バースト境界、実衝突、両種の配置が混在する場合の担当切り替え、配置拒否・停止、全解除、勝利、AI、計105打の在庫保存と物理安定性を確認。ブラウザーでも実際の指戻し・操作中断によるキャンセル、旧キャンセル位置を通る打球、双方の完成・バースト後の配置と次の打球、混在配置、停止、画面サイズ、再戦・退出を確認。
