# ビリヤード（v304）

承認された画面案の緑フェルト、木枠、金の金具、象牙色の数字玉を使う独立モード。

- `table.webp`: 画面案を参照して画像生成した、玉・文字・UIのない盤面。800×1200。枠を含む画像で、数字・玉・キュー・照準は Canvas で描画。
- SE は `bbAudio()` で合成。打球、玉同士の衝突、クッション、結合、10完成、交代、補充、勝敗。音量制限と衝突音の連続再生制限あり。停止・ミュート・退出時に再生中の音を止める。
- 白い玉を経由して数字を衝突させる。数字どうしは合計10以下なら結合し、元の数字を保持した剛体として移動・回転する。白い玉は結合せず、10超過は反発。
- 15点先取。通常テンクルと同じ役判定 `calcPts` を使用：役なし1、ワンペア2、ツーペア3、スリーカード4、ストレート5点。5＋5は役なし、ストレートは1・2・3・4。同じ数字3個以上はスリーカード。1打で複数の10を作ればそれぞれ加点。
- 役ありの10を最初の1打で作ると追加の1打。連続2打まで。追加の一打で役を作っても次は相手の番。プレイヤー・AI共通。勝利した場合は追加なし。
- 初期盤面は数字12個＋白い玉1個、すべて未結合。1×3、2×2、3×3、4×2、5×2をシャッフルし、接触しない12か所に配置。途中の塊はどちらも利用可能。手札・ポケット・解除操作なし。
- 補充は相手への交代時だけ。追加の一打の前には補充しない。数字12個／独立した塊6個を目安に、通常は数字16個まで追加。残った塊では10を作れない場合は補数を最大2個追加して詰みを解消。既存の玉を再配置しない。
- 役完成時は元の玉が中心へ収束し、金色の細粒・輪・役名・得点・構成数字を表示。高い役ほど輪と音の余韻を増す。勝利の決定打も見えるようリザルトは1.65秒後。既存のフェルト・木枠画像はそのまま。
- 打球音は短い乾いたアタックと低い胴鳴りを強さに連動して合成。役完成音は柔らかい鐘と和音、追加の一打は短い2音。
- AIは3段階。公開盤面から候補を作り、プレイヤーと同じ物理計算で試射し、役の得点・追加の一打・結合・相手への取りやすさを評価。強さは候補数と照準の誤差で調整。
- 操作は盤面のどこからでも引っぱって離す。引っぱる距離で強さを調整、元へ戻して離すと中止。壁際でも操作可能。キーボードは左右で角度、上下で強さ、スペースで打球。

調整値は `BB_CFG`。物理は120 Hzの固定刻み。タブ非表示・フォーカス喪失で自動停止。

検証: `node tests/billiards.cjs`（初期配置、5役、15点勝利、双方の追加打球と上限、補充時機と密度、物理、AIを含む）。ブラウザーではスマホ相当の入力、AIの交代、得点演出、SE発火、一時停止、再戦・ホーム、320〜768px幅の表示を確認。
