# カラールーム（v301）

ホームの「カラールーム」から開始。既存の対戦モードとは独立。

- 青とオレンジ50%ずつで開始。どちらかが100%になった瞬間に決着。時間制限なし。
- 1〜5の手札10枚、同じ数字は最大3枚。自分専用の場に4枚以内で10を作る。
- 10を作っても空いた手札は補充せず、10枚すべてを使い切った時だけ新しい10枚を配る。完成演出は700ms。相手が完成しても自分の場は消えない。
- 3枚目・4枚目の合計による出札制限を廃止。10超過も出せる。出した後、残りの手札と最大4枚の枠で10が不可能なら、場の札だけを即座に捨てる。残りの手札は保持。AIも同じルール。
- 低彩度の青と黄土色を床へ重ね、石の模様を残す。手札は幅・高さを広げ、下端から余白を取って上へ移動。
- 場の札をタップして元の手札位置へ戻せる。「場を戻す」で全て戻す。
- 役は既存の `calcPts` と共通。役なし4%、ワンペア7%、ツーペア10%、スリーカード14%、ストレート18%を塗り返す。5＋5は役なし。
- AIは自分の手札のみから10の組合せを探索。3段階で手の間隔と効率的な役を選ぶ確率を変更。調整値は `index.html` の `CR_CFG`。
- ポーズ、画面非表示、フォーカス喪失で進行停止。ホームへ戻る際はタイマー・描画・再生中の音を破棄。

## 素材

このモード用に生成した背景とSE。外部の期限付きURLには依存しない。

- `room.webp`: 明るい石造りの部屋。絵の具、札、UIはゲーム側で描画。
- `splash.mp3`: 小〜中規模の絵の具の飛散音（約1秒）。
- `wave.mp3`: 強い役の大きな波と飛散音（約1.5秒）。
- `win.mp3`: 勝利の短いチャイム（約1.5秒）。

SEはRunwayの音声生成で制作。札の配置音と敗北音はWeb Audioで合成。専用の効果音ON/OFFあり。

## 確認

`node tests/color-room.cjs` で役、補充、手札の組合せ、AI、取り消し、ポーズ、両側の勝敗を検証。

実ブラウザでは320×568〜768×1024の5サイズでタップ・補充・ポーズ・音・勝利・再戦・ホームへの遷移を確認。

既存の `tests/survival-mode.cjs` は追加前のv299でも同じ補充枚数のアサーションに失敗する。今回のモード追加でその既存仕様・テストは変更していない。
